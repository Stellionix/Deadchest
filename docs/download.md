## DeadChest - Download

### Free edition

You can download the free edition of DeadChest from the official sources below:

- [Modrinth](https://modrinth.com/plugin/dead-chest)
- [BukkitDev](https://dev.bukkit.org/projects/dead-chest)
- [CurseForge](https://www.curseforge.com/minecraft/bukkit-plugins/dead-chest)
- [GitHub](https://github.com/stellionix/Deadchest) (build from source)

!!! warning
    Avoid downloading the plugin from unofficial mirrors.

### Pro edition

Get [DeadChest Pro on BuiltByBit](https://builtbybit.com/resources/deadchest-pro.131511/).
Pro adds chest menus and previews, live tracking, optional teleportation, and
administrator history with restoration of eligible expired loot.

See the [Pro feature guide](pro/index.md) and follow the
[Pro installation and migration guide](pro/installation.md). Pro replaces the
free plugin: install only one edition at a time.

### Requirements

- Minecraft server version: **1.13+**
- Java runtime: **Java 8+**

Supported server implementations include:

- Bukkit
- Spigot
- Paper
- Tuinity
- Purpur
- Most Bukkit/Spigot derivatives
- Folia
