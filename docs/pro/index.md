# ⭐ DeadChest Pro

DeadChest Pro includes the free edition's death chests, XP storage, holograms,
protection settings and partial collection. It adds tools for finding active
chests and returning eligible expired inventories to their owners.

[Get DeadChest Pro on BuiltByBit](https://builtbybit.com/resources/deadchest-pro.131511/){ .md-button .md-button--primary }
[Installation and migration](installation.md){ .md-button }

Install only the Pro JAR. It replaces the free plugin; no client mod, economy
plugin or remote license activation is required.

## Pro features

| Feature | Where to start |
| --- | --- |
| Browse active chests and preview their contents | [Chest menu](player-tools.md#chest-menu) |
| Follow direction, distance and remaining time | [Live tracking](player-tools.md#live-tracking) |
| Teleport near a chest with configurable restrictions | [Teleportation](teleportation.md) |
| Inspect history and return eligible expired loot | [History and restoration](history.md) |
| Set permissions, languages and Pro options | [Configuration](configuration.md) |

New chest creation and direct inventory collection support automatic recovery
after an interrupted transfer in both editions. Pro history restoration also
supports this recovery. See [recovery and backups](history.md#recovery-and-backups)
for its scope.

## First steps

1. [Install Pro or migrate from the free edition](installation.md).
2. Run `/dc menu` in game to browse your chests.
3. Enable teleportation if you want to offer it to players. It is disabled by default.
4. Give trusted staff the history and restoration permissions.

The [core configuration](../configuration.md) and
[core commands](../commands-and-perms.md) still apply to Pro.
